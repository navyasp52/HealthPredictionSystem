# Health Prediction System

## Technologies Used

Frontend:

* React JS
* Axios

Backend:

* FastAPI
* SQLAlchemy

Database:

* SQLite

## Features

* Add Patient
* View Patients
* Update Patient
* Delete Patient
* AI Health Prediction

## Prediction Rules

* Glucose > 140 → Possible Diabetes Risk
* Haemoglobin < 12 → Possible Anemia Risk
* Cholesterol > 240 → Possible Heart Disease Risk
* Otherwise → Healthy
